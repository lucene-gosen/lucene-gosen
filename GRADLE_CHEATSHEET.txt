## Gradle Wrapper

Use Gradle Wrapper (`./gradlew`) instead installed Gradle.
If you want to upgrade Gradle, change gradle/wrapper/gradle-wrapper.properties

## Cheatsheet

ant compile              -> ./gradlew compileJava
ant compile-tests        -> ./gradlew compileTestJava
ant javadoc              -> ./gradlew javadoc
ant jar -Ddictype=ipadic -> ./gradlew jarWithIpaDic
ant jar -Ddictype=naist-chasen -> ./gradlew jarWithNaistChasen
cd dictionary;ant clean  -> ./gradlew :dictionary:clean
ant dist                 -> ./gradlew dist

## UniDic tasks

Preprocess UniDic source (lex.csv + matrix.def → dictionary.csv + connection.csv):

```
$ ./gradlew :dictionary:preprocessUnidic
```

Preprocess using CRF weights from model.def (Phase 2):

```
$ ./gradlew :dictionary:preprocessUnidic -PuseModel=true
```

Override the cost scaling factor (default 700):

```
$ ./gradlew :dictionary:preprocessUnidic -PuseModel=true -PcostFactor=500
```

Compile preprocessed CSVs to binary .sen files:

```
$ ./gradlew :dictionary:compileUnidic
```

Build jar bundling the compiled UniDic:

```
$ ./gradlew jarWithUnidic
```

Force-recompile UniDic from scratch (clean + preprocess + compile):

```
$ ./gradlew :dictionary:rebuildUnidicDic
```

Remove compiled UniDic .sen files only:

```
$ ./gradlew :dictionary:cleanCompiledUnidic
```

The UniDic source directory is configured by `unidicDictDir` in `gradle.properties`
(default: `new_dictionary/unidic-cwj-202512_full`).

## For committer

There are some environment properties in gradle.properties.
For uploadArchives, we need set some properties in ~/.gradle/gradle.properties

Example :

```
signing.keyId=KEY_ID
signing.secretKeyRingFile=/Users/johtani/.gnupg/secring.gpg
sonatypeUsername=USER_NAME
sonatypeFullname=FULL_NAME
```

Then,

```
$ ./gradlew uploadArchives
```

the task asks you sshkey password and Sonatype password.
